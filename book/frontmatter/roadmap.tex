\section*{Coverage of the source books}

The table below maps every chapter and appendix section of the two source books to the place
where this book covers it. \textsf{LLM} is \emph{Build a Large Language Model (From Scratch)}
(Raschka, 2024); \textsf{RM} is \emph{Build a Reasoning Model (From Scratch)} (Raschka). The
material is reorganised so that overlapping topics appear once. For example, LLM~5.3 (temperature
and top-$k$) and RM~4.4--4.5 (temperature and top-$p$) are both developed in
\cref{ch:pretrain,ch:scaling}, and each later chapter builds on the earlier one. The margin tags
inside the chapters give the precise locations.
